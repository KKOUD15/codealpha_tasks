# 📖 Overview

This repository contains all the projects completed during my **Mechanical Design & Simulation Internship** at **CodeAlpha**.

The internship focused on applying engineering principles through **CAD modeling**, **mechanical assemblies**, **finite element analysis (FEA)**, **motion simulation**, and **CNC manufacturing preparation** using **SOLIDWORKS 2025**.

The goal was to strengthen practical skills while following an industrial engineering workflow from concept to manufacturing.

---

# 🎯 Internship Objectives

- Design professional 3D mechanical parts
- Create complete mechanical assemblies
- Perform structural analysis using Finite Element Analysis (FEA)
- Simulate mechanical motion and kinematics
- Prepare CNC machining operations
- Improve engineering documentation
- Apply Design for Manufacturing (DFM) principles
